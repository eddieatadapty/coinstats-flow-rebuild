# CoinStats Growth Audit

**Live → https://eddieatadapty.github.io/coinstats-flow-rebuild/**

Five ideas to turn more CoinStats users into subscribers, each built into a clickable version of CoinStats's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Open on the search they typed | +10–20% CR to trial |
| 02 | Ask one thing, then use it on the paywall | +10–20% CR to trial |
| 03 | Put $164.99 on the yearly card | +10–15% ARPU |
| 04 | Show your 4.8 stars where they pay | +10–15% CR to trial |
| 05 | Answer ✕ with your $119.99 year | +10–15% ARPU |

Every price, rating and feature comes from CoinStats's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for CoinStats. They overlap, so they don’t add up. Nothing here is investment advice: the screens show your own features and prices only.

Static single page, no build step: `python3 -m http.server`.
